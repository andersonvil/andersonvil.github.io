Synthetic course resource

Interpreting associations and causal claims

A fictional 90-minute workshop that tests how a teaching resource can combine a learning objective, a short dataset, executable code, and an accessible handout.

Level
Synthetic undergraduate workshop
Institution
None — demonstration only
Language
English
Software
Python 3, standard library only

Learning objectives

  • Distinguish a descriptive association from a causal estimate.
  • Identify the assumptions needed to interpret a coefficient.
  • Reproduce a small grouped-average calculation from synthetic data.

Session sequence

  1. Read the data-generating story and identify the unit of observation.
  2. Compute group averages by hand and with the demonstration script.
  3. List alternative explanations for the observed difference.
  4. Rewrite an overconfident conclusion using appropriately limited language.
